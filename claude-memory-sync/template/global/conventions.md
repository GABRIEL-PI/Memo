# Global Conventions

This file holds cross-project conventions, preferences, and standing context
that Claude Code should apply everywhere, regardless of which project is
currently open (e.g. naming preferences, tone, recurring tooling choices).

Curate this manually. Nothing here is written automatically by
`detect-and-map` — it only touches `projects/<slug>/`. Edit freely and commit
through the normal `sync.sh` / `sync.ps1` flow.
